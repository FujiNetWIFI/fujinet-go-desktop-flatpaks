FujiNet Go desktop flatpaks

Add the remote once, then install and update like any other flatpak:

flatpak remote-add --user --if-not-exists fujinet-go https://fujinetwifi.github.io/fujinet-go-desktop-flatpaks/fujinet-go.flatpakrepo
flatpak install --user fujinet-go online.fujinet.go.nes.gnome

Each app comes in a GNOME and a KDE frontend (.gnome / .kde).
